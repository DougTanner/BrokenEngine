### Both-endpoint commands

Game-specific commands compiled into both executables; send to either port. Unlike the side-specific commands below, they never return `unknown command` for the "wrong" build.

- `collection_layout_capacity_fixture`: no params. SOA physical-layout-capacity retention self-check on the real `MissilesPostRender`, driving production `SharedCollectionRead` through logical capacities 100 -> 70 -> 60 -> 150 on one reused instance. Returns `{"build":"server"|"client","steps":[{"label","logicalCapacity","physicalCapacity","reused"}],"sharedRowMismatches":int,"sharedRowsPreserved":bool,"passed":bool}`, plus client-only `{"clientSoundsZeroed":bool,"clientSoundsNonZeroCount":int}` or server-only `{"serverMembersEqualShared":bool}`. `passed` requires both shrinks to reuse the 100-wide buffer, the >100-row read to reallocate once (physical 150), every shared row preserved, and — on the client — the full physical `puiSounds` layout (rows 70-99 included) zeroed, or — on the server — `serverMembersEqualShared` true. Requires `kbDebugInput`.
- `registry_fixture`: no params. `engine::FrameRegistry` self-check driving the real public API over fixed local arrays, with no frame, collection, or allocation involved. Returns `{"build":"server"|"client","rankingDistribution":[int,int,int],"reacquiredId":int,"tieWinnerId":int,"ownershipRowCount":int,"passed":bool}` plus the boolean checks `radiusRejected`, `alignmentRejected`, `rankingCorrect`, `resolveStableAfterPermutation`, `removedIdResolves`, `releaseClearedHandle`, `reacquireCorrect`, `highCountRankingCorrect`, `highCountReleaseCleared`, `highCountReleaseCountCorrect`, `tieCorrect`, `ownershipCountCorrect`, `foreignLookupMatches`, `uuidLookupHit`, `uuidLookupMiss`, `uuidLookupWithoutGlobalIds`, `assignHitReturnedTrue`, `assignHitIsolated`, `assignMissReturnedFalse`, `assignMissChangedNothing`. `passed` requires every one of those true except `removedIdResolves`, which must be false. Together they prove the fixed fewest-subscribers-then-smallest-angle distribution, radius and alignment acceptance and rejection, stable resolution after the source rows are permuted and the context rebuilt, a dropped source id failing to resolve then releasing and reacquiring, a 256-vs-1 existing-subscription ranking choosing the less-subscribed source and releasing one source-A handle to leave its count at 255, an exact tie going to the lower layer and row, `CountRegistryRows` returning the bound row count, an ownership layer bound through `RegistryIdBytes` over a foreign `id_t` resolving the same uuids as a natively typed one, `RegistryUuidByGlobalId` hits and misses (including against a layer with no global-id column), and `AssignRegistryClientGuid` changing exactly the matched row on a hit and no row on a miss. Requires `kbDebugInput`.

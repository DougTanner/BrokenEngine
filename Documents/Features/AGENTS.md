# Features

Ideas saved for another day, whether or not the design is decided. Feature plans are tracked Markdown documents, but execution is manual: WorktreeCli never validates, claims, stores locks for, or changes `Documents/Features`.

Use existing subject-area subdirectories and retain clear scope, invariants, and acceptance criteria. Work wanted soon belongs in `Documents/Plans`, the only tree covered by `/next-plan`, or in `Documents/Investigations`, by the deciding test in `Documents/AGENTS.md` `## Planning Trees`.

A design deferred because it is not needed yet keeps a `Revisit When` line naming the concrete trigger that would make it worth doing, so a later reader can tell a rejected idea from a waiting one. `Graphics/IslandFlowMaskUsage.md` is the pattern.

# Targets ledger — ChangeWorkflowTargetedConsolidation

One row per target. Fields:

- File, Section — where the target lives.
- Key phrase — a literal that locates the target; match it ignoring line
  breaks and indentation.
- Baseline span — the replaced text at baseline commit
  591184a4dbf802ac2f6d3c2cf9de168916e4714d, as line range plus first and last
  words. Line numbers are for the baseline only; locate by Key phrase.
- Action — rewrite | merge | delete.
- Recheck — the sibling Plan(s) that may already have changed or removed this
  text: `NeverTriage` (ChangeWorkflowNeverTriage), `StepChecklistScript`
  (ChangeWorkflowStepChecklistScript); `none` otherwise.
- Intent — the restructuring the row makes, used only by the Plan's
  changed-text rule.
- Reason — why; for delete rows, the evidence status.
- Meaning-shift flag — `none`, or the reading the coherence review must
  confirm.
- Words — baseline span words -> proposed words, counting each
  whitespace-separated token that holds a letter or digit.
- Proposed — the exact replacement, between the `<<<` and `>>>` lines,
  already wrapped and indented for the target file. A delete row's Proposed
  is empty.

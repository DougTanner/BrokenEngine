# Round texels to bytes in texture encoding

## Context

Converting a float texel to a byte should not bias it, but
`Texture::EncodeBlocks` truncates
(`DataPacker/Source/ExportJobs/Texture/Texture.cpp:405`), and
`Texture::PixelToUint32` (`:356` to `:359`) does the same for the
`VK_FORMAT_R8G8B8A8_UNORM` route, `ExportTexture`'s default format. Level 0 of an
8-bit source holds whole values (`:247` to `:250`), so truncation is exact there.
`MakeMipmaps` (`:284`) produces fractional values, so every later level loses its
fraction.

The measurement that shows it is one image exported twice, once with green
inverted. Exact coding would make g_a + g_b - 255 zero, and truncation makes it -1
wherever a value is fractional, since floor(x) + floor(255 - x) is 254 there. So
the mean below is twice the one-way bias, which is about -0.3 to -0.5 of a byte
step per channel. On the 4096 by 4096 BC5 map of
`MolniaAnimated.fbx.glb`, with red byte-identical on every level:

| Mip | Mean of g_a + g_b - 255 |
|---|---|
| 0 | +0.1064 |
| 1 | -0.7442 |
| 2 | -0.7319 |
| 3 | -0.6687 |
| 4 | -0.5995 |
| 5 | -0.5983 |
| 6 | -0.6412 |
| 7 | -0.7969 |
| 8 | -0.8878 |
| 9 | -0.9643 |
| 10 | -1.0000 |

Mip 0, with no truncation, shows BC5 encoder noise alone. Render reach is small:
on that scene the two encodes differ on 883 of 65936 model mask pixels above noise
floor 4 and 283 above floor 8, with mean signed luminance change -0.014. The
bias was seen verifying a green inversion, and it is outside that change's
boundary.

The fix is small and its cost is not. Rounding re-encodes every mip chain. 363
BC intermediates are tracked: 280 files of 686 MiB under `Engine/Data/Islands` and
83 under `Projects/BrokenEngineSandbox/Data`, 983 MiB together. Rewriting them adds
blobs of about that size to Git history.

## Design

The author's recommendation is to round to nearest in both conversions through
one local helper in `Texture.cpp`, since there are five call sites, using
`std::lround` over the clamped value as `ExportAudio.cpp:76` does for its samples.
Rationale: one rule for both routes keeps the two formats consistent, and a whole
value is unchanged, so level 0 of an 8-bit source stays byte-identical.

Bump each version that owns a changed output, as
`DataPacker/Source/ExportJobs/AGENTS.md` `## Shared Pipeline` requires:
`ExportTexture::kiVersion`, the raw value of `ExportScene::kiVersion`, and
`ExportIsland::kiTextureVersion`. The island bump is the expensive one. The author
recommends it anyway, because otherwise tracked island textures disagree with the
exporter until each is next edited; leaving islands truncated is the alternative
to weigh at claim time.

`MigrateLegacyIntermediates` needs nothing, because it skips marked files.

## In scope

- The two float-to-byte conversions named above and their shared helper.
- The three version bumps, and the tracked outputs they regenerate.

## Out of scope

No change to `MakeMipmaps`, its filter or color space, BC encoder parameters,
`ToR16`, the `SaveJpegSidecar` casts (`:587` to `:598`), `Texture::Save`, the
intermediate or chunk formats, or `ModelVertex`. No new tracked fixture model,
harness command or unit test.

## Acceptance criteria

- Exporting one map and a scratch, uncommitted green-inverted copy, then decoding
  both BC5 chains, gives a mean of g_a + g_b - 255 within 0.25 of zero on every
  mip, against the table's -0.60 to -1.00 on mips 1 to 10. Mip 0's +0.1064 is the
  reason for that limit: it is the size of encoder noise alone.
- Level 0 of each regenerated BC intermediate from an 8-bit source is
  byte-identical to before.
- `/compile` of DataPacker, ModelViewer and the BrokenEngineSandbox client and
  server succeeds with every tracked intermediate regenerated, and a Local
  generation build restores the sparse data trees it needs.
- A ModelViewer capture of `Models\MolniaGltf\scene.gltf` returns code `ok`, and
  an `/agent-harness` client and server launch reaches a running game session,
  with neither log holding `DEBUG_BREAK at` or a CRC mismatch.

Live setup: `/compile` `-Target ModelViewer -Configuration Debug`, then the
`/agent-harness` capture with that `-ModelPath`. The supplied evidence records no
ordered setup for the game session; establish and record it during execution.

## Notes

Future implementation is Tier 3: trigger is build/bootstrap coordination that can
block other sessions. Landing rewrites 363 tracked binary files, so any session
holding an edit to one meets a binary conflict, and every checkout rebuilds its
texture packs once. `git sparse-checkout disable` is needed before editing
`Engine/Data/Islands`, and a Local generation build through `/compile` restores it.

The change itself is one subsystem's tool behavior. Texel bytes change and formats
do not, so there is no serialization layout change. Texture payloads reach only
client GPU sampling and the client map thumbnail, outside PostRender state, so
determinism/CRC, replay, wire, threading and allocation are unaffected. The island
chunk fingerprint covers Color and AO, so island chunks re-pack too.

No prerequisite Plan or mandatory coordination constraint was identified. Any Plan
that bumps a scene version or edits a tracked texture first simply re-exports
once more.

# Main-Session Skill Layout

Use this checklist after selecting the main-session consumption shape in
[`skill-skeleton.md`](skill-skeleton.md) `## Consumption shapes`.

1. Keep the complete ordered workflow in `SKILL.md`. Done when its recognized
   sections follow `skill-skeleton.md` `## Section order`.
2. Link focused references from `SKILL.md` only when the invoking session needs
   them. Done when every linked detail has one owner and every bundled link
   resolves.
3. Omit `references/worker.md`. Done when package inspection finds no worker
   entry file.

Delegated actions remain ordinary steps in the invoking session's workflow.
Configure host metadata from execution needs under the independent frontmatter
rules in `/external-skill-creator` validation mode.
